# Dynamic Search Portal

This project demonstrates a simple search portal that interacts with the Groq Cloud API. The interface is built with HTML, Tailwind CSS and vanilla JavaScript.

## Setup
1. Place your Groq API key in `script.js` by setting `GROQ_API_KEY`.
2. Open `index.html` in a modern browser.

## Features
- Enter a search query and receive mock search results generated by Groq.
- Contextual action buttons suggest further tasks.
- "✨ Expand" provides more information about a result.
- "✨ Summarize Results" gives a concise summary of all current results.

Note that network access is required for API calls to Groq Cloud.
